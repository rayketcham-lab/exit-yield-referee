# Exit Yield Referee

> Sweeps idle stablecoins only when net yield beats exit penalty and fees.

## Overview

Finance teams at cloud-native SaaS companies often hold USDC or USDT across exchange wallets, treasury accounts, and tokenized money-market funds. The manual habit is to chase the highest quoted APY, but that ignores redemption delay, early-exit penalties, withdrawal fees, and minimum terms. For a platform engineer scaling from ten to five hundred services, this is the same drift as duplicated credentials across twelve Kubernetes namespaces and an operations note nobody trusts: idle cash becomes another resource with no owner.

Exit Yield Referee is a self-hosted policy bot that treats exit friction as a real cost of carry. It ingests balances from one exchange adapter plus manual CSV import, reads a YAML catalog of stablecoin cash equivalents, and computes net edge for each option: candidate yield minus baseline yield, minus exit penalty, fees, delay drag, and a configurable risk floor. It then builds a boring liquidity ladder: instant funds for payroll, next-day funds for vendor bills, and only excess above thresholds moves to longer terms. If the extra yield does not cover the cost of leaving, it refuses the product and leaves cash in the safest bucket.

The MVP is deliberately narrow: read-only first, dry-run sweep plans, an audit log in SQLite, and approval-gated execution through one destination account. It gives CFOs a defensible rule set, gives platform engineers a deployable internal service with policy in Git, and turns a stale operations note into a repeatable daily check.

## Market Analysis

Stablecoin balances are becoming normal operating float for SaaS payroll, ad spend, cloud bills, and FX payments, yet most yield tools show gross APY without redemption friction. The gap is a policy-driven sweep bot that refuses terms whose exit penalty eats the extra yield and only moves cash when net edge clears a floor. It serves finance ops leaders and platform engineers who need auditable, boring automation across multiple wallets.

## MVP Scope

MVP includes YAML product catalog for five stablecoin reward or lending options, CSV liquidity calendar for payroll and vendor bills, Coinbase Advanced Trade read-only adapter plus manual balance import, FastAPI service with SQLite audit log, dry-run sweep plan across instant, next-day, seven-day, and thirty-day buckets, and approval-gated transfer to one destination account. It does not custody private keys, support arbitrary DeFi vaults, tax filing, multi-currency FX, or automatic market-making.

## Getting Started

### Prerequisites

- Python 3.12+
- [uv](https://docs.astral.sh/uv/) (recommended) or pip


### Installation

```bash
git clone https://github.com/rayketcham-lab/exit-yield-referee
cd exit-yield-referee

# Using uv (recommended)
uv venv && source .venv/bin/activate
uv pip install -e ".[dev,test]"

# Or using pip
python -m venv .venv && source .venv/bin/activate
pip install -e ".[dev,test]"
```

### Running

```bash
uvicorn exit_yield_referee.app:app --reload
```

### Testing

```bash
pytest tests/ -v
```
